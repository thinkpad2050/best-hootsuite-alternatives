# Contributing to Awesome Hootsuite Alternatives

Thank you for your interest in contributing to this list! We welcome new additions, updates, and improvements from the community to make this the best resource for social media management tools.

## How to Contribute

### Adding a New Tool

If you know of a great social media scheduling or management tool that is missing from this list, please submit a Pull Request (PR) with the following details:

1.  **Tool Name:** The official name of the tool.
2.  **Best For:** Who is the target audience? (e.g., Enterprise, Agencies, Startups, Creators).
3.  **Website:** Provide the direct link to the tool's homepage.
4.  **Notes/Highlights:** A brief description (max 1-2 sentences) highlighting its key features or unique selling points.

**Formatting Rules:**
-   Ensure the tool is added to the appropriate category (Top Suites, Focused Scheduling, AI/Automation, Open Source).
-   Keep the description objective and helpful.
-   Check that the link works.
-   Maintain alphabetical order within categories if possible.

### Improving Existing Content

Feel free to submit a PR to:
-   Fix broken links.
-   Update tool descriptions or categories.
-   Improve formatting or consistency.
-   Add relevant badges or information.

## Submitting a Pull Request

1.  Fork this repository.
2.  Create a new branch for your changes (e.g., `feature/add-new-tool`).
3.  Commit your changes with a clear message (e.g., `Add ToolName to Focused Scheduling`).
4.  Push to your fork and submit a Pull Request to the `main` branch.

## Issues

If you find an issue with the list or a broken link but don't want to submit a PR, please feel free to open an Issue describing the problem.

Thank you for helping us maintain this awesome list!
